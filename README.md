# ⚡ ByteForge

🚧 **Under Development**

**ByteForge** is a high-performance C++ memory management and profiling engine designed to explore efficient allocation, memory tracking, heap management, and low-level systems engineering.

### 🛠️ Built With

* C++
* C++20
* CMake
* STL

### 🔬 Focus

`Memory Management` · `Custom Allocators` · `Profiling` · `Performance` · `Systems Programming`

> More features and documentation are currently in development.
